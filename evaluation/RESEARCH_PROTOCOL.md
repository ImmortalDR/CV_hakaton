# Проверка исследовательских изменений, 9 октября 2026

Цель: проверить правила доказательности и измерить их последствия, не подбирать
веса по известному test. Веса ранжирования и метки датасета 1.0.0 не меняются.
Его test уже просмотрен при прошлых аудитах: это регрессионный benchmark,
а не новая слепая оценка обобщения. Новую экспертную разметку не имитируем.

Сначала категория и явный фильтр ФСП, затем ранжирование в категории.
Полная рекомендация означает met для всех обязательных **навыков**;
unknown и unmet остаются отдельными причинами частичного соответствия.
Стаж остаётся неподтверждённым, это не обещание соответствия всем условиям.
Сравнить старую смешанную выдачу с полными рекомендациями: P@5 (знаменатель 5),
precision по фактически выданным (null для пустой), recall всех рекомендаций,
unknown/unmet в топе, корректный отказ в пулах без релевантных кандидатов.
Фильтр ФСП признаёт только поддерживаемый провайдер, не произвольные записи.

Банк 1.2.0: прежние 4 задания/2 семейства/30 минут и порог 75%; дополнительно
оба задания основного навыка Python/SQL должны быть верны. Это консервативная
политика команды, а не эмпирически калиброванный порог. Порядок перемешивается
воспроизводимо. Уже начатые старые попытки оцениваются по сохранённой версии.
Грейды существующих пользователей не пересчитываются и не понижаются.

Для каждой из 6 категорий: 100 вариантов dev для выбора самого частого
числового ответа каждого семейства; другие 100 вариантов probe для проверки
стратегии угадывания. Это нижняя граница уязвимости, не модель реального человека.
Проверить эталоны независимыми вычислителями, blueprint и воспроизводимость.
Четыре профиля на категорию: не знает ничего, знает только основной навык,
знает всё, знает всё с независимой вероятностью ошибки 20% на вопрос.
По 100 probe-вариантов: доля успеха, средние баллы, попарное совпадение исходов,
разность долей верных ответов strong/weak по семействам. Группы заданы до
измерения; идеальное разделение детерминированных групп заложено в симулятор.
Пары повторов зависимы, не считаются независимыми испытуемыми.

Не делаем выводов о профессиональной валидности Junior/Middle/Senior,
сопоставимости сложности на людях, защите от LLM или рыночной релевантности.
Следующий человеческий этап: слепое ревью содержания и уровней, пилот повторных
форм с зафиксированными независимыми метками, ошибки/сложность по семействам.
