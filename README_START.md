# Стартовый комплект для GPT Astra Codex

Это комплект исходных материалов и инструкций для разработки. Готового приложения в нём ещё нет.

## Как использовать

1. Распакуй ZIP в `/root`: внутри архива уже есть единственная папка `hakaton/`. Итоговый путь — `/root/hakaton`, без дополнительного уровня `hakaton/hakaton`.
2. Если workspace уже существует, объединяй каталоги с сохранением существующих файлов. Например: `unzip -n hakaton_astra_workspace.zip -d /root`. Ключ `-n` пропускает существующие файлы; это не команда обновления уже изменённых инструкций.
3. Открой `/root/hakaton` в Codex и вставь весь текст `PROMPT_ASTRA.md`.
4. При желании проверь комплект: `python3 /root/hakaton/scripts/verify_workspace.py`. Скрипт проверяет пути, размеры и SHA-256, но не оценивает качество кода.

Все 8 131 файла первоначальной подборки включены без изменения содержимого. Сохранены лицензии, `_SOURCE_COMMIT.txt` и исходные комментарии; ошибки этих комментариев разобраны отдельно. Снимки репозиториев не содержат `.git`, зависимости и веса моделей не установлены. Для сборки приложения может потребоваться интернет.

Комплект содержит оригинальные материалы, уже имеющиеся у пользователя, чтобы его можно было перенести целиком. Они не должны автоматически попадать в публичный git: соответствующие пути исключены в `.gitignore`. Код, фактически перенесённый в приложение, должен храниться в репозитории вместе с необходимыми лицензиями.

GitHub проверен через подключённый GitHub: репозиторий доступен; на момент подготовки веток не было. Никаких коммитов или других изменений в GitHub при подготовке этого комплекта не делалось.
