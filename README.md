# ФСП · карьера

**Обратный найм по подтверждённым навыкам.** Кандидат проходит тест, работодатель получает объяснимую подборку и приглашает лично — сразу с зарплатной вилкой. Контакты открываются конкретной компании после согласия кандидата.

[Открыть демо](https://85-137-26-131.sslip.io/) · [Маршрут для жюри](docs/delivery/FOR_JURY.md) · [Презентация](demo/FSP_FINAL_2026-10-21.pdf)

## Что умеет платформа

- **Подтверждать навыки:** Python / бэкенд и аналитика / SQL, уровни Junior–Senior, варианты задач и проверка на сервере. Неудачная попытка не понижает грейд.
- **Объяснять подбор:** обязательные и желательные навыки, источники доказательств, неизвестные компетенции и сохранённые подборки.
- **Соединять кандидата с компанией:** приглашения с зарплатой, принятие или отказ, диалог и PDF-профиль с учётом прав доступа.
- **Продолжать оценку:** адресные задания компаний по отдельному согласию. Оценка работодателя и достижения ФСП не меняют профессиональный грейд.

**Стек:** React + TypeScript · FastAPI · PostgreSQL · Docker Compose · Caddy.

## Запустить локально

Нужны Git, Python 3 и Docker с Compose v2. Первой сборке требуется интернет.

```bash
git clone --branch main https://github.com/ImmortalDR/CV_hakaton.git
cd CV_hakaton
python3 scripts/configure.py
docker compose up -d --build --wait
```

Откройте **http://localhost:3080**. Кнопки «Я кандидат» и «Я работодатель» открывают демонстрационные кабинеты. Для своего сценария создайте два тестовых аккаунта с разными ролями. Данные сохраняются между перезапусками.

Локально без SMTP подтверждение почты имитируется. Для настоящих писем и восстановления пароля настройте SMTP по инструкции ниже. Профили-примеры и достижения ФСП — демонстрационные.
