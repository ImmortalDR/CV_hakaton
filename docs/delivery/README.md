## Сборка документов

Из корня репозитория с установленными requirements-dev.lock и шрифтами DejaVu:

```bash
.venv/bin/python scripts/build_delivery.py --docs-only
.venv/bin/python scripts/check_documentation.py
```

Команда --docs-only обновляет только руководство; существующая презентация
не пересобирается. Для визуальной проверки DOCX его дополнительно экспортируют
LibreOffice в отдельный каталог audit, не поверх основного PDF.
Исторические отчёты (VALIDATION_2026-10-07.md, release-checks.json,
RESEARCH_V2.pdf/DOCX) сохранены со своими датами и не обозначаются новой проверкой.
