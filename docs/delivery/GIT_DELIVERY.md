# Размещение кода

Репозиторий: https://github.com/ImmortalDR/CV_hakaton
Рабочая ветка: `codex/fsp-mvp`.

Первоначальный remote был пуст. Код и материалы отправлены через
подключённый GitHub API: обычный git push по HTTPS на сервере не имел
учётных данных. Ветки не перезаписывались принудительно, чужие коммиты
не удалялись. Корневая main содержит указатель на рабочую ветку.

Разработка велась локальными коммитами (включая a28f287, 471cf78, cc40dbd),
а API создал отдельную историю опубликованных снимков. После отправки
локальная история разработки сохранена в `codex/fsp-local-history`;
`codex/fsp-mvp` соответствует опубликованной ветке origin.
Исходные файлы и локальные журналы аудита сохранены вне runtime-приложения.

Код: feat-коммит и последующий коммит материалов/проверок. Точный итоговый
commit указан в сообщении сдачи и доступен через `git log -1`.
