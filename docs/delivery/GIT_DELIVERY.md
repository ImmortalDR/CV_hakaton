# Состояние кода и публикации

Репозиторий: https://github.com/ImmortalDR/CV_hakaton . Рабочая ветка: `codex/fsp-mvp`. Прикладная версия на стенде — `c4bca3c`; последующие коммиты синхронизируют документацию. Локальный HEAD смотреть через `git log -1`.

**Актуальные изменения не опубликованы: пользователь повторно запретил push до отдельного решения.** Ранее обычный push остановился из-за отсутствия авторизации git-транспорта. Наличие коннектора не означает настроенный доступ shell и не является основанием заменять историю снимком.

После разрешения: настроить доступ при необходимости, fetch, проверить расхождение и чужие коммиты, сохранить пользовательский WIP, выполнить обычный push без force, проверить удалённый SHA и ссылки. Сейчас эти действия не выполняются. Pck2 остаётся частичным до публикации, Pck5 — до факта отправки организаторам.

Первоначальная версия была опубликована через GitHub API; прежняя история разработки сохранена в codex/fsp-local-history. Это историческая публикация, не утверждение о совпадении нынешнего HEAD с origin. Старые bundle не включают последующие изменения: проверить базу и состав перед использованием.

Не включать .env, пароли, личные адреса, резервные копии и непросмотренные архивы. Соседний остановленный проект intellect-org-os не относится к этой сдаче.
