# Код и публикация

Основная ветка: [main](https://github.com/ImmortalDR/CV_hakaton/tree/main). Она содержит приложение, исследования V4, инструкции и материалы сдачи. Объединение выполнено по прямой просьбе владельца; прежний запрет на push отменён последующими указаниями.

[История объединения, исходные SHA и проверки](../REPOSITORY.md). История сохранена merge-коммитами, без force-push и подмены снимком. Старые рабочие ветки сохраняются как исторические ссылки; новые изменения начинаются от `main`.

[Ссылки для организаторов](SUBMISSION_LINKS.md). Публикация Git-истории не означает отправку сообщения организаторам: этот внешний шаг выполняет команда.

Секреты, резервные копии, непросмотренные локальные архивы и частные исследовательские данные не включены в поставку. Рабочий сервер и соседние проекты при объединении не изменялись.
