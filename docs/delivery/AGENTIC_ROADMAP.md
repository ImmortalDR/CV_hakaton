# Следующий уровень платформы — архитектурный план

Описанное ниже — план развития, не текущая реализация. На стенде работает MVP; эти компоненты — следующий этап.

---

Следующую версию платформы мы проектируем как **Agentic Talent Intelligence System**.

Архитектура объединяет гибридный семантический поиск, cross-encoder reranking и Agentic GraphRAG по подтверждённым компетенциям. Специализированные агенты анализируют требования, собирают доказательства и готовят рекомендации через MCP-инструменты, сохраняя состояние процесса и контроль пользователя.

Для сложных запросов предусмотрена маршрутизация к MoE reasoning-моделям. Следующие этапы — исполняемая проверка практических навыков кодом, доменное дообучение ранжирования на экспертных предпочтениях и взаимодействие карьерных агентов по протоколу A2A.

**Цель:** каждая рекомендация объяснима, проверяема и связана с реальным результатом кандидата.

## Связь с тем, что уже работает

| Компонент плана | Основа в текущем MVP |
|---|---|
| Agentic GraphRAG — «Почему этот кандидат?» | «Почему в подборке» + «Результаты и источники» на стенде |
| Evidence Auditor — «навык не подтверждён» | «Не проверено» + объяснение неполного соответствия |
| Executable Assessment — оценка кодом | Адресные задания компании с оценкой результата |
| Neural Matching + Reranking | Matching v1.2.0, веса на выборке, версионирование формулы |
| Continuous Learning | Зафиксированный holdout, hard-negative сценарии, versioned weights |
