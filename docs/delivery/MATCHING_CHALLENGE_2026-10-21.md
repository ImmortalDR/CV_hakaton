# M01: проверка конкурирующих доказательств

21 октября 2026. Формула matching-1.2.0 оставлена без изменения: обязательные навыки 30, желательные 15, тест до 45, ФСП до 10. Пользователь подтвердил: общий балл определяет порядок внутри категории, а непроверенные и невыполненные обязательные требования явно показаны.

[Сценарии](../../evaluation/final_matching_challenge.json), [процедура](../../evaluation/final_matching_challenge.py), [результат](../../evaluation/final_matching_challenge_results.json).

12 авторских сценариев, 26 вымышленных профилей (профили могут повторять структуру, это не независимая рыночная выборка). Указаны основания каждого случая и проверяемые отношения; независимых разметчиков нет. Старый набор и его метки не изменялись. Новые веса по challenge не подбирались.

Проверяются полное покрытие против сильного теста, ФСП против теста, самодекларация, unknown/unmet, отсутствие полных совпадений, несколько обязательных требований, несколько грейдов, равные баллы, недоверенный источник ФСП, допуск по категории, потолок бонуса и желательный навык против теста. Дополнительные проверки: рост тестового балла не ухудшает итог; самооценка и стаж не меняют балл.

**Получены две изменившиеся пары** между старой формулой 60/15/20/5 и текущей. Все заявленные инварианты выполнены. Для каждого случая опубликованы оба порядка, баллы и доля частичных соответствий в верхней части списка. В смешанных грейдах сначала действует группировка категории; числовой балл разных категорий напрямую не сравнивается.

Независимых меток профессиональной релевантности нет, поэтому P@5/NDCG для нового набора намеренно `null`. Назначить «правильный порядок» по проверяемой формуле означало бы замкнуть оценку на саму себя. Эти сценарии показывают последствия выбранной политики, а не доказывают улучшение найма. Старое P@5=0,80 без прироста остаётся историческим результатом на восьми контрольных запросах.

В ходе визуального аудита обнаружена отдельная ошибка: UI ставил все полные совпадения перед частичными, изменяя серверный порядок. Исправлено: один порядок по категории и общему баллу, отдельная заметная маркировка пробелов. При отсутствии полных совпадений остаётся явное сообщение; частичный результат не выдаётся за полное соответствие.

Следующее измерение качества — реальные запросы работодателей, независимо оценённая полезность первых кандидатов, оценка по запросам, отдельно от поведения формулы. Без таких данных не заявляем доверительный интервал рыночного прироста или оптимальность весов.
