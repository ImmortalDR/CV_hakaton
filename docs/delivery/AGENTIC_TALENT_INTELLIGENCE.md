# Agentic Talent Intelligence — технологическая концепция развития платформы

Предлагаемая следующая версия системы — мультиагентная платформа подбора специалистов, объединяющая reasoning-модели, GraphRAG, нейросетевое ранжирование и исполняемую проверку навыков.

Описанные ниже компоненты — план развития. На презентации необходимо отделять уже реализованные возможности от прототипов и перспективной архитектуры.

## 1. MoE Reasoning Engine — интеллектуальный анализ требований

Система распределяет задачи между моделями: компактная модель извлекает специализацию и условия из запроса; reasoning-модель анализирует сложные требования и противоречия; сервер проверяет структуру ответа и бизнес-правила. В качестве эксперимента — Qwen3-235B-A22B (MoE, ~22 млрд активируемых параметров на токен).

## 2. Neural Matching — нейросетевой поиск кандидатов

Гибридный dense–sparse retrieval (Qwen3-Embedding + Qdrant) с Reciprocal Rank Fusion и cross-encoder reranking. Семантическое сходство отображается отдельно от подтверждённой квалификации.

## 3. Agentic GraphRAG — граф доказательств компетенций

Граф «кандидат → навык → задание → результат → дата». Агент собирает доказательства, каждый вывод содержит идентификатор свидетельства и источник. Предположения модели отделяются от подтверждённых результатов.

## 4. Multi-Agent Orchestration

Роли: Requirements Agent, Retrieval Agent, Evidence Auditor, Communication Agent — через MCP-инструменты с ограниченными правами. Состояние сохраняется через PostgreSQL checkpoints (LangGraph).

## 5. Executable Assessment — генеративные задания с проверкой кодом

LLM создаёт вариацию задания из шаблона. Ответ кандидата запускается в изолированной среде (gVisor). Property-based testing (Hypothesis) ищет контрпримеры.

## 6. Continuous Learning

Экспертная разметка парных предпочтений, hard-negative mining, LoRA fine-tuning, контроль на отдельной выборке (Langfuse).

## 7. A2A Talent Network

Агент работодателя взаимодействует с агентом кандидата по протоколу Agent2Agent: запрашивает подтверждения компетенций, передаёт условия, получает уточнения — человек подтверждает финальное действие.

## Приоритет внедрения

Neural Matching + Agentic GraphRAG + ограниченная мультиагентная оркестрация.

Сквозной сценарий: свободный запрос → согласованные критерии → нейросетевой поиск → проверка доказательств → объяснённая подборка → подготовленное приглашение.
