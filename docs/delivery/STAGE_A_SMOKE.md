БД, затем действует через развернутый API и браузер. Пароли случайны, живут в
памяти, не выводятся. В `finally` скрываются только кандидаты текущего прогона;
записи не удаляются. Это не проверка регистрации/почты. Для одного успешного
теста ответы вычисляет независимый решатель по серверным параметрам; это не
оценка знаний человека. Общие review-аккаунты не используются для мутаций.
