# Предыдущие проверки: два окна, повтор и продолжение

21 октября 2026. [Машиночитаемый отчёт](evidence/jury_replay_2026-10-21.json).

Серверный набор: **132 PASS**, одно предупреждение устаревания в тестовой зависимости. Сборка TypeScript/Vite и контейнеров выполнена. Навигация: **11 групп** — Back/Forward, прямые ссылки, черновики теста, приглашения, чат, выход и мобильное меню.

**Полностью завершены два последовательных прохода на локальной базе и два на публичном сайте с C7D0B82B. По 10 групп проверок сессии и сбоев пройдены локально и публично; ошибок JavaScript нет.**

Сквозная проверка использует два независимых браузерных контекста и **те же аккаунты при повторе**, без сброса данных. Проверяются история и объяснения, поиск по номеру, подбор, согласие и PDF, диалог в обе стороны, задание с оценкой 85/100, приостановка/возобновление, ФСП и отзыв/повторное согласие. В контрольных точках вкладка закрывается и открывается по сохранённому адресу; перед вторым повтором пересоздаются оба браузерных контекста с сохранёнными cookie.

Проверки сбоев включают HTTP 503 и зависание загрузки компании, ошибку первой загрузки заданий, таймаут истории, повторную загрузку, восстановленный/истёкший вход и смену аккаунта в соседней вкладке. Фактическое число завершённых проходов и проверок для локальной и публичной версий — в JSON выше.

Воспроизведение на отдельной базе после сборки frontend:

```bash
npm run build --prefix apps/web
COOKIE_SECURE=false .venv/bin/python scripts/run_local.py .venv/bin/pytest -q tests
.venv/bin/python scripts/run_local.py .venv/bin/python tests/browser_navigation.py
.venv/bin/python scripts/run_local.py .venv/bin/python tests/run_jury_isolated.py
```

Браузерные сценарии создают и удаляют только собственные временные базы. Для авторизованной проверки публичного демонстрационного стенда: `tests/browser_jury.py --base-url URL --runs 2` и `tests/browser_sessions.py --base-url URL`. Первый добавляет помеченные вымышленные приглашения и задания в общие аккаунты, проверяет отзыв и восстановление доступа; старые записи не удаляет. Второй проверяет сессию и загрузку, не создавая бизнес-записей. Письма не отправляются. Не запускайте сквозной сценарий параллельно ручной проверке того же общего кандидата.

Проверка закрытия вкладки относится к уже сохранённым действиям. Не заявляется сохранение любого несохранённого текста, остановка сроков тестирования, отсутствие сбоев сети или изоляция посетителей, одновременно работающих в одном общем аккаунте. Независимый пилот и реальная доставка SMTP этим прогоном не проверяются.
