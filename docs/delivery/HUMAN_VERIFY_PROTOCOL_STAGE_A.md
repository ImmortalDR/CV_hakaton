## 0. Как пользоваться (30 секунд)

- Ставьте у каждого шага: PASS / FAIL / SKIP; вписывайте дату и короткое наблюдение. Ни один результат ниже за вас не заполнен.
- FAIL по must (помечены ★) = нельзя отправлять Pck5. SKIP must тоже не доказывает готовность.
- Не чините сами в этой сессии — только фиксируйте; баг верните команде.
- Review-логины только из [FOR_JURY](FOR_JURY.md); свои данные не вводить. Пароли берите там, здесь они не дублируются.
- Отрицательный Q1 исправлен и проверен: 18 групп smoke и отдельная HTTP503/delayed-ACK контрпроба PASS. Технических FAIL нет. До отправки нужны GitHub push и ваши отметки ниже; агент их не проставлял.
- Выделите 25–40 минут на экранные шаги. Внешняя отправка и реальные 7 дней — отдельно. Открывайте роли в отдельных браузерных профилях: приватные окна одного профиля могут делить вход.
- Обозначения ниже: **К** = кандидат `review.candidate.fsp@example.org`; **Р** = работодатель `review.employer.fsp@example.org`; **Д** = другая компания `review.employer2.fsp@example.org`. В каждой строке указан нужный логин этим обозначением. Для шага без входа логин — «не нужен».
- Начинайте каждый экранный шаг на https://85-137-26-131.sslip.io/. Если общий аккаунт занят, тест ограничен пересдачей или нужного состояния нет — SKIP с причиной и передача команде для подготовки отдельного review-сценария. Не сбрасывать БД/таймер, не создавать вымышленные результаты тестов и не вводить чужие данные.
