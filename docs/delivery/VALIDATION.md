## Независимые вычисления и синтетические уровни

Протокол зафиксирован до финального измерения. `evaluation/oracles.py`
не импортирует генератор или оценщик. Unit-набор проверяет 600 уникальных
вариантов, 2400 вопросов по 6 категориям; воспроизводимость и blueprint.
Отдельная оценка содержит 12 синтетических персон, 20 вариантов для каждой,
3 уровня: 720 уникальных попыток и 2880 проверок эталона независимым решением.

Для персон заранее заданы известные семейства и ожидаемый уровень;
у двух «noisy-middle» дополнительно вероятность ошибки 0,2. Получено
235/240 совпадений ожидаемого уровня: **97,92%**. Средняя доля наиболее
частого результата по вариантам — **97,92%**. Это симуляция правила, не
доля правильно оценённых реальных программистов.

| Ожидаемый → полученный | Не подтверждён | Junior | Middle | Senior |
|---|---:|---:|---:|---:|
| Не подтверждён | 80 | 0 | 0 | 0 |
| Junior | 0 | 40 | 0 | 0 |
| Middle | 2 | 3 | 75 | 0 |
| Senior | 0 | 0 | 0 | 40 |

Пять ошибок — чувствительность короткого теста к случайным пропускам у
синтетических Middle. Четыре вопроса не дают надёжной оценки человека
по всем компетенциям уровня. Эту слабость нельзя устранить заявлением
о «равной сложности» параметрических вариантов; нужен пилот и более широкий банк.

## Качество подбора

Train отсутствует: модель не обучается, веса фиксированы. Dev: 16 профилей,
2 запроса. Test: 48 профилей, 8 запросов, другие ID. Это разные вымышленные
персоны, но специально повторяемые типы ошибок и категории; статистической
независимости выборки реальных людей эти данные не обеспечивают.
Явные relevance labels хранятся в fixture, не получены вызовом rank_candidate.
Автор разметки — разработка; независимых экспертов ФСП: **0**.

Baseline: пересечение заявленных навыков и стаж внутри той же категории.
P@5 всегда делит число релевантных в первых пяти на 5, даже при нехватке
релевантных кандидатов. Это намеренно сурово к пустой выдаче и коротким спискам.

| Запрос test | P@5 MVP | P@5 baseline |
|---|---:|---:|
| Python Junior | 1,00 | 0,60 |
| Python Middle | 1,00 | 0,60 |
| Python Senior | 1,00 | 0,60 |
| Data Junior | 1,00 | 0,60 |
| Data Middle | 1,00 | 0,60 |
| Data Senior | 1,00 | 0,60 |
| Python + React без доказательства React | 0,00 | 0,00 |
| Python + обязательное тестирование | 0,40 | 0,20 |
| **Среднее** | **0,80** | **0,475** |

В шести простых случаях доказательства вытесняют громкие самодекларации.
В запросе React все пять выдаваемых карточек нерелевантны по разметке;
интерфейс честно показывает unknown, но выдача всё равно заполнена.
В запросе с двумя обязательными навыками есть только два полностью
релевантных кандидата; оставшиеся три получают неполное соответствие.
Эти ошибки сохранены в `evaluation/results.json`. Веса после просмотра
test не перенастраивались.

## Найденные и исправленные проблемы

- Черновое семейство граничных условий всегда имело ответ 2. В 1.1.0 набор
  входов меняется содержательно; независимый oracle проверяет расхождения.
- Историческое объяснение могло раскрыть скрытый позже стаж: теперь оно
  проверяет актуальную настройку при каждом чтении.
- Первое выполнение проверки 90 дней вернуло 401: истекла тестовая сессия.
  Исправлен тест часов с явным продлением своей сессии; правило API не ослаблено.
- Первоначальная frontend-сборка завершилась 137 из-за памяти. Отдельно
  найден рекурсивный анализ Rollup; настройка сборки исправлена и перепроверена.
- npm audit обнаружил проблему Vite 6.4.1; обновлён до 6.4.4.
  pip-audit обнаружил 7 записей у Starlette 0.46.2; FastAPI/Starlette обновлены
  до 0.142.3/1.3.1, полный набор тестов повторён. Финальные сканы чистые
  относительно доступных им баз, не являются полным аудитом безопасности.

`python3 scripts/verify_workspace.py --inputs-only`: 8141 исходный файл
совпадает с предоставленными SHA-256; 8131 архивный путь разрешён через
фактический вложенный каталог fsp_mvp_bundle. 22 редактируемых рабочих

дал ложные missing и ожидаемые отличия рабочих документов; это исправление
пути проверки, а не восстановление или перезапись исходников. Хеширование
не объявляется содержательным чтением.
