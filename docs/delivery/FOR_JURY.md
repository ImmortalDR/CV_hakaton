# Возможный сценарий проверки для жюри

**[Открыть демонстрационный сайт](https://85-137-26-131.sslip.io/)**

Платформа помогает работодателю найти специалиста по подтверждённым навыкам. Кандидат проходит тест и выбирает, кому открыть контакты. Работодатель видит основания подбора и отправляет личное предложение с зарплатой.

На знакомство с готовыми примерами достаточно около **10–15 минут**. Регистрация и полное прохождение теста для этого не нужны.

## Перед началом

Откройте сайт в двух независимых окнах: обычном и инкогнито либо в двух разных браузерах. Так вы сможете одновременно посмотреть обе роли. Две обычные вкладки одного браузера используют общий вход.

1. На странице входа под формой нажмите **«Начать новый демопроход»**. Появится ссылка на вашу пару демонстрационных аккаунтов.
2. Скопируйте эту ссылку и откройте её во втором независимом окне.
3. В первом окне нажмите **«Я кандидат»**, во втором — **«Я работодатель»**. На телефоне разделы открываются кнопкой **«Все разделы»**.

В новом проходе уже есть опубликованный кандидат Junior с двумя результатами тестирования — **100% и 50%**. Приглашения, диалоги и задания пока пусты. Используйте только вымышленные данные. Одна и та же ссылка возвращает к этому проходу и сохраняет его действия; новый проход создаёт отдельную пару аккаунтов и не меняет предыдущие.

Если нажать кнопки ролей без создания нового прохода, откроются **общие демоаккаунты** с действиями прошлых посетителей. Для последовательной проверки ниже используйте именно новый демопроход.

## 1. Посмотрите, что видит кандидат

В окне кандидата откройте **«Обзор»**. Здесь показаны специализация, подтверждённый уровень и видимость профиля для работодателей.

Перейдите в **«Подтверждение навыков»**. В истории откройте результат **100%**: видны 8 заданий, правильные ответы и объяснения. Затем откройте результат **50%**: часть ответов неверна, но ранее подтверждённый Junior сохранён. Если история не загрузилась, нажмите **«Обновить историю»**.

В текущем тесте 8 заданий на 30 минут; для подтверждения уровня нужны минимум 6 правильных ответов, из них минимум 3 по основному навыку — Python или SQL. Для этого демонстрационного прохода начинать новый тест не нужно.

**Что показывает этот шаг:** уровень опирается на результат теста. Неудачная попытка не понижает уже подтверждённый уровень. Примеры результатов в демопрофилях созданы для демонстрации.

## 2. Подберите специалиста от имени компании

В окне работодателя откройте **«Подбор кандидатов» → «По потребности»** и задайте:

| Поле | Значение для примера |
|---|---|
| Специализация | Python / бэкенд |
| Допустимые уровни | Junior |
| Python | Обязательный |
| Тестирование | Желательный |
| HTTP / API | Не учитывать |
| Только с достижениями ФСП | Не отмечать |

Нажмите **«Сформировать подборку»**. В карточке любого кандидата прочитайте **«Почему в подборке»** и раскройте **«Результаты и источники»**. Здесь видны подтверждённые навыки, результаты тестирования и составляющие общего балла.

Теперь сделайте **HTTP / API обязательным** и снова сформируйте подборку. У кандидата без подтверждения этого навыка появится отметка **«Не проверено»**, а при неполном соответствии обязательным требованиям — пояснение об этом.

**Что показывает этот шаг:** система объясняет соответствие запросу и явно обозначает недостающие доказательства. Общий балл помогает сравнивать кандидатов внутри одной категории; он не означает вероятность найма.

## 3. Отправьте предложение и посмотрите ответ кандидата

Верните HTTP / API в **«Не учитывать»** и сформируйте подборку заново.

Используйте **номер кандидата вашего демопрохода**: он указан в строке **«Отдельный демопроход · кандидат №…»** над содержимым страницы в обоих окнах, а также в разделе **«Мой профиль»** кандидата. В каждом новом проходе номер другой.

**Номер — идентификатор кандидата, а не его имя.** До принятия приглашения настоящее имя и контакты кандидата скрыты от работодателя. Они открываются только той компании, чьё приглашение кандидат принял кнопкой **«Принять и раскрыть контакты»**. Для остальных работодателей профиль остаётся анонимным.

В окне работодателя раскройте строку **«Отдельный демопроход · кандидат №…»** и нажмите **«Найти кандидата этого прохода»**. Либо откройте **«Подбор кандидатов» → «Банк кандидатов»**, нажмите **«Сбросить фильтры»**, введите свой номер в поле **«Номер кандидата»** и нажмите **«Применить фильтры»**. Номер остаётся видимым и после раскрытия имени и контактов.

Скачайте PDF кнопкой со значком загрузки в карточке: до согласия в нём нет имени и контактов. После принятия приглашения скачайте PDF снова — данные станут доступны этой компании.

1. В карточке нажмите **«Пригласить»**. Например, укажите «Разработка API на Python» и зарплату **100 000–150 000 ₽ в месяц**. Отправьте приглашение и закройте подтверждение кнопкой **«Готово»**.
2. В окне кандидата откройте **«Приглашения»**. Найдите предложение, прочитайте задачи, зарплату и сведения о компании.
3. Нажмите **«Принять и раскрыть контакты»**.
4. Вернитесь в окно работодателя, откройте **«Приглашения»** и обновите страницу. У принятого предложения доступны контакты и кнопка **«Открыть диалог»**.
5. При желании обменяйтесь короткими тестовыми сообщениями через два окна.

Если вы вернулись по ссылке к уже начатому проходу, продолжите с существующего приглашения. Для повторения с исходного состояния создайте новый проход, как описано ниже.

**Что показывает этот шаг:** кандидат видит условия до начала общения. Контакты открываются пригласившей компании после принятия предложения. В карточке кандидата также можно скачать PDF-профиль; его содержимое зависит от предоставленного компании доступа.

## 4. Проверьте дополнительные возможности

**Задание от компании.** У работодателя откройте «Задания от компаний», выберите кандидата своего прохода. Укажите название «Проверка обработки ошибок API», вопрос «Как повторять запрос при временной ошибке API и предотвращать дублирование операции?» и критерии «Ограничение повторов, задержка между ними, защита от дублей». Нажмите «Предложить план кандидату».

В том же разделе у кандидата нажмите «Согласиться и включить выдачу», отправьте ответ: «Ограничиваю число повторов, увеличиваю задержку, использую ключ идемпотентности». У работодателя нажмите «Обновить задания», поставьте 85 и добавьте обоснование, затем сохраните оценку. После обновления кандидат видит **85/100**, а его уровень остаётся **Junior**. Приостановите и снова включите выдачу: уже выполненное задание не должно выдаваться повторно немедленно.

**Достижения ФСП.** У кандидата откройте «Достижения ФСП» и нажмите «Связать демонстрационный ФСП ID». Junior сохраняется. У работодателя заново сформируйте подборку с параметрами из шага 2 и без требования HTTP / API: у вашего кандидата общий балл увеличится с **90 до 96** за счёт ФСП. Это демонстрационная интеграция, без подключения к официальному реестру.

**Управление доступом.** В «Моём профиле» кандидата отключите публикацию и сохраните. После обновления окна работодателя профиль исчезает из поиска, PDF недоступен, диалог закрыт. Включите публикацию обратно: старое согласие не восстанавливается. Для нового доступа отправьте ещё одно приглашение и примите его в окне кандидата. Эти действия в отдельном демопроходе не затрагивают других посетителей.

## Повторите проверку с начала

Выйдите из кабинетов. В первом окне нажмите **«Начать ещё один демопроход»** (или «Начать новый демопроход», если это новый браузер), скопируйте **новую** ссылку во второе окно и снова выберите роли. Не создавайте два отдельных прохода для двух ролей.

Начальные состояния повторяются: Junior, результаты **100% и 50%**, профиль опубликован, контакты скрыты, приглашений, диалогов, заданий и достижений ФСП нет. Идентификаторы, даты и числовые варианты заданий могут отличаться; правила, оценки и последовательность действий одинаковы. Старую ссылку можно сохранить для возврата к предыдущему проходу.

Общий кандидат **C7D0B82B** на публичном стенде сохранён отдельно. Он доступен через обычные кнопки ролей без нового прохода; его история и действия прошлых посетителей не сбрасываются.

## Если хотите пройти весь путь самостоятельно

Зарегистрируйте кандидата и работодателя на двух доступных вам почтовых адресах, подтвердите их по ссылкам из писем. Заполните профиль кандидата и компанию работодателя.

У кандидата пройдите тест выбранного уровня, затем разрешите публикацию профиля. После успешного подтверждения уровня его можно найти со стороны работодателя и пройти сценарий приглашения выше. На сам тест отводится до 30 минут — этот вариант занимает больше времени, чем знакомство с готовыми примерами.

Если повторный тест недоступен, страница покажет причину и ближайшую дату. В общих демоаккаунтах это может быть следствием предыдущего прохождения. Если предложение или сообщение не появилось, обновите соответствующий раздел или страницу.
