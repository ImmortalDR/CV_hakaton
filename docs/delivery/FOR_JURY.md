# Возможный сценарий проверки для жюри

**[Открыть сайт](https://85-137-26-131.sslip.io/)**

Кандидат подтверждает навыки тестом. Работодатель подбирает специалиста по этим результатам и отправляет предложение с зарплатой. Кандидат решает, кому открыть имя и контакты.

Основной сценарий занимает около **10–15 минут**. Регистрироваться и заново проходить тест не нужно: доступны готовые демонстрационные аккаунты.

## Подготовьте два окна

1. В **обычном окне** на странице входа нажмите **«Я кандидат»**.
2. Откройте этот же сайт **в инкогнито или другом браузере** и нажмите **«Я работодатель»**.

Два обычных окна одного браузера используют общий вход. Два окна инкогнито тоже делят вход между собой. Поэтому используйте именно обычное окно + инкогнито либо два разных браузера. Далее переходите между этими окнами; выходить из аккаунтов на каждом шаге не нужно.

Если вы открываете сценарий впервые, а сайт сразу показывает сохранённый кабинет, нажмите «Выйти» и выберите нужную кнопку на странице входа. Так оба окна будут работать именно с общими аккаунтами этого сценария, даже если раньше использовался другой профиль. При дальнейшем продолжении выходить не нужно. На телефоне разделы открываются кнопкой «Все разделы».

Аккаунты общие: предыдущие приглашения, сообщения и результаты могут уже присутствовать. **Они не сбрасываются при входе.** Используйте только вымышленные данные.

## 1. Посмотрите профиль и результаты кандидата

В окне кандидата откройте **«Мой профиль»**. Запишите **номер кандидата**. На публичном стенде у кандидата из кнопки «Я кандидат» это **C7D0B82B**. На собственной установке номер может отличаться.

Для поиска работодателем должны быть включены **«Согласен на обработку данных для работы профиля»** и **«Публиковать профиль в банке кандидатов»**. Если профиль скрыли во время предыдущей проверки, включите эти пункты и нажмите **«Сохранить профиль»**.

Откройте **«Подтверждение навыков»**. В истории нажмите **«Посмотреть»** у завершённой попытки: видны задания, ответы, оценка и объяснения. Результаты сохраняются после обновления страницы и повторного входа. При ошибке загрузки используйте **«Обновить историю»**.

Начинать новый тест для этого сценария не требуется. Для самостоятельного тестирования страница показывает правила, доступные уровни и ограничения пересдачи. Неудачная попытка не понижает ранее подтверждённый уровень.

## 2. Подберите специалиста

В окне работодателя откройте **«Подбор кандидатов» → «По потребности»**:

| Поле | Значение |
|---|---|
| Специализация | Python / бэкенд |
| Допустимые уровни | Junior |
| Python | Обязательный |
| Тестирование | Желательный |
| HTTP / API | Не учитывать |
| Только с достижениями ФСП | Не отмечать |

Нажмите **«Сформировать подборку»**. Прочитайте **«Почему в подборке»**, раскройте **«Результаты и источники»**. В карточке видны основания соответствия и составляющие балла.

Для сравнения сделайте **HTTP / API обязательным** и сформируйте подборку снова. У кандидата без доказательства этого навыка появится **«Не проверено»** и пояснение о неполном соответствии. Верните HTTP / API в «Не учитывать» и снова сформируйте подборку.

Баллы сравниваются внутри категории; это не вероятность найма. Редактирование условий само по себе не меняет сохранённую подборку — нужно нажать кнопку формирования.

## 3. Отправьте предложение кандидату

Откройте **«Банк кандидатов» → «Сбросить фильтры»**, введите **C7D0B82B** в поле **«Номер кандидата»**, нажмите **«Применить фильтры»**. При собственной установке используйте номер из шага 1.

**Это идентификатор, а не имя.** До принятия приглашения имя и контакты скрыты от работодателя. После согласия они доступны только пригласившей компании. Номер остаётся в карточке и после раскрытия имени, поэтому искать нужно по номеру. Если предыдущая проверка уже открыла этой компании контакты, они могут быть видны сразу.

1. Нажмите **«Пригласить»**. В предложении напишите, например, **«Проверка жюри — 1. Разработка API на Python»**. Укажите зарплату от **100 000** до **150 000 ₽** и отправьте приглашение.
2. В окне кандидата откройте **«Приглашения»**. Найдите **именно предложение с вашим текстом**, прочитайте условия и нажмите **«Принять и раскрыть контакты»**.
3. В окне работодателя откройте **«Приглашения»**. Найдите это же предложение: статус «Принято», контакты доступны.
4. Нажмите **«Открыть диалог»**, отправьте сообщение. Откройте диалог этого предложения в окне кандидата и ответьте. Кнопка **«Обновить»** загружает новые сообщения.
5. В карточке кандидата скачайте PDF значком загрузки. При действующем согласии в нём есть контакты. Без согласия PDF содержит обезличенный профиль.

Новые предложения расположены выше старых. Если приглашение уже принято, продолжайте с диалога. Если отклонено, создайте другое предложение. При временной ошибке загрузки компании нажмите **«Загрузить компанию повторно»** в открытом окне: введённое предложение и зарплата сохраняются.

## 4. Дополнительные проверки

**Задание от компании.** У работодателя откройте «Задания от компаний». После принятия приглашения кандидат появится в получателях; при необходимости нажмите «Обновить задания». Создайте план с узнаваемым названием, например «Ошибки API — проверка 1»:

- Задача: «Как повторять запрос при временной ошибке API и предотвращать дублирование операции?»
- Критерии: «Ограничение повторов, задержка между ними, защита от дублей».

У кандидата в этом разделе найдите **свой план**, согласитесь на выдачу и отправьте ответ. Например: «Ограничиваю число повторов, увеличиваю задержку, использую ключ идемпотентности». У работодателя обновите задания, поставьте **85**, добавьте обоснование и сохраните оценку. Кандидат увидит **85/100**; профессиональный уровень не изменится.

Можно приостановить и снова включить выдачу. Это не создаёт немедленно второе задание: дата следующей выдачи указана в плане. Для завершения этой проверки нажмите **«Закрыть план»**. Для нового упражнения создайте другой план.

**Достижения ФСП.** Откройте соответствующий раздел у кандидата. Если демонстрационный профиль ещё не связан, нажмите «Связать демонстрационный ФСП ID». Если уже связан, посмотрите имеющиеся достижения. Они добавляют баллы внутри категории, но не повышают Junior до Middle. После изменения заново сформируйте подборку работодателя. Подключение к официальному реестру здесь не используется.

**Отзыв доступа — необязательная проверка.** Отключите публикацию кандидата и сохраните профиль. Обновите окно работодателя: кандидат исчезнет из поиска, PDF и диалог станут недоступны. Затем включите публикацию обратно. **Прежнее согласие на контакты при этом не возвращается:** отправьте новое приглашение с отличимым текстом и примите его у кандидата. После этого общение снова доступно. В общих аккаунтах изменение видимости влияет и на других посетителей, проверяющих этого кандидата.

## Как прерваться, продолжить и повторить

Сохранённый профиль, результаты тестов, отправленные приглашения, сообщения, ответы и оценки остаются на сервере. Можно закрыть вкладку и вернуться. Если вход закончился, снова нажмите **«Я кандидат»** или **«Я работодатель»** в соответствующем окне — откроются те же аккаунты. Все окна инкогнито после закрытия теряют вход; повторный вход восстанавливает доступ к сохранённым действиям.

Продолжайте по текущему статусу:

| Что видно | Следующее действие |
|---|---|
| Предложение отправлено | Найдите его у кандидата и примите |
| Предложение принято | Откройте его диалог |
| Ответ на задание «На проверке» | Поставьте оценку у работодателя |
| Оценка уже сохранена | Посмотрите её у кандидата |
| Выдача приостановлена | Включите её в том же плане при необходимости |
| Профиль скрыт / доступ отозван | Включите публикацию, отправьте и примите новое приглашение |

Текст, который вы ещё не сохранили или не отправили, не считается завершённым действием. Перед закрытием формы сохраните его. Срок уже начатого теста и срок задания продолжают идти после закрытия браузера; это не сброс истории.

**Чтобы повторить сценарий второй раз**, используйте те же два окна и тот же номер кандидата. Повторите шаги 1–3, добавив в текст предложения **«Проверка жюри — 2»**. Для задания используйте новое название. Предыдущие записи останутся, а новые появятся рядом с ними. Повторно подтверждать грейд или отвязывать ФСП не нужно.

## Если хотите начать с собственного аккаунта

Зарегистрируйте кандидата и работодателя на двух доступных вам почтовых адресах, подтвердите почту, заполните профиль и компанию. Кандидату нужно пройти тест и разрешить публикацию. Затем используйте его номер для поиска работодателем. Этот вариант занимает больше времени и также требует двух независимых сессий.
