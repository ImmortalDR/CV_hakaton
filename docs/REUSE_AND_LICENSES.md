# Компоненты и происхождение

Это план заимствований, не список уже перенесённого в приложение кода. Полные лицензии и `_SOURCE_COMMIT.txt` сохранены в каждом исходном проекте. При переносе запиши конкретные файлы, исходный commit, изменения и необходимые notices в `THIRD_PARTY_NOTICES.md` приложения. Не выдавай наличие публичного исходника за разрешение игнорировать его условия.

| Источник | Лицензия в приложенном снимке | Использовать | Не переносить автоматически |
|---|---|---|---|
| HireDesk | MIT | React-компоненты, страницы двух кабинетов, визуальные паттерны | Mongo/Express доменную модель прямого отклика, dev-конфигурацию |
| mominalix ATS | Apache-2.0 | Схему «требование, доказательство, неизвестно», идеи разложения оценки | Скоринг, эвристическую confidence, английский NLP как готовый русский |
| PrairieLearn | AGPL-3.0, отдельные части MIT; EE удалена | Принцип шаблонов, seed, серверного эталона; собственная реализация предпочтительна | Весь сервис с отсутствующими импортами; непроверенный код EE |
| OpenResume | AGPL-3.0 | При необходимости изучить PDF-рендерер с учётом лицензии | Английский парсер как решение русского импорта |
| Reqcore | AGPL-3.0 | Справочная схема ATS, если реально нужна | Второе ATS-ядро и его модель владения кандидатом |
| Docling | MIT для кода; условия моделей отдельно | Позже, при доказанной потребности в распознавании | Тяжёлый импорт до готовности основного сценария |
| Sentence Transformers | Apache-2.0 для кода; условия моделей отдельно | Позже, подходящая модель после проверки русского и выигрыша качества | Весь исходный репозиторий как runtime-зависимость |
| catsim | BSD-3-Clause | Исследование IRT после содержательной валидации | Симулированные метрики как доказательство качества реальных задач |
| Judge0 | GPL-3.0 | Позже, если действительно нужно исполнение кода | Привилегированную инфраструктуру ради обязательного MVP |
| Kaggle notebooks | Условия переиспользования кода отдельно не подтверждены обзором | Анализ ошибок и идей | Готовую обученную модель, метрики и копирование без проверки |
| Kaggle CSV souptikghosh | В исходном сборнике указан MIT | Локальные демо-заготовки после очистки | Эталонные грейды/истину для оценки и публикацию контактов как настоящих |

CSV содержит 815 строк и 32 точных дубля; в нём нет проверенных грейдов и меток релевантности. Для публичной демонстрации лучше собственные явно синтетические имена, адреса в example-доменах и безопасные тестовые контакты. 1-ГБ датасета `hse-hackathon` в комплекте нет; он не нужен для выбранного MVP.

Новые зависимости устанавливай из проверенных источников с фиксированными версиями. Перед выбором конкретной ML-модели проверь её карточку, языки, ограничения и лицензию; веса в архив не включены. Выбор лицензии собственного приложения должен учитывать фактически включённые компоненты, а не всю папку референсов.
