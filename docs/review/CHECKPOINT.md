## Окружение ревью

Python 3.12; локальная `.venv` с pip, pymupdf1.28.2, python-pptx1.0.2,
python-docx1.2.0, Pillow12.3.0. Для probes: numpy2.2.6, scipy1.15.3,
scikit-learn1.6.1. Первые свежие wheels NumPy2.5.3 требовали X86_V2 и
не запустились; это зафиксированный неуспешный запуск, затем версии заменены.
Установлен LibreOffice Impress24.2.7. Docker не перезапускался.

Первая попытка apt update завершилась ошибками индексов; отдельный sources
файл с HTTPS в tmp/apt позволил повторить установку. Системный sources не
редактировался. Инструменты ревью не являются runtime-зависимостями MVP.
