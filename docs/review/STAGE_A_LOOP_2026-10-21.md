# Целевое ревью цикла Stage A

Область: submit/Answers, Overview/Invitations, smoke и тесты Stage A. Продолжение существующего ревью, не новый полный аудит архивов.

1. Ознакомление: прочитаны канон Stage A, verify/by-task, schema Answers, submit/save lifecycle, Overview/Invitations, smoke, test_stage_a и conftest. Обнаружены отсутствие серверного подтверждения и безусловная подсказка приглашений.
2. Связи: submit блокирует строку попытки; до выставления completed проверяет пропуски, учитывая пустые строки. Draft и время при отказе сохраняются. UI отправляет флаг только после подтверждения. Invitations получает текущий профиль из общего состояния, Overview выбирает следующий шаг по тем же флагам.
3. Негативные сценарии: отсутствие/false подтверждения, whitespace, сохранность draft/expiry, UI отмена, published/hidden verified, адресный revoke. Q5 проверяет ярлык, видимую арифметику и контекст; Q6 дату в московской зоне и неизменность срока. Проверки выполняются отдельными командами, результаты — в VERIFY_STAGE_A_PROTOCOL.

Границы: поиск/автоматические проверки не считаются чтением. Архивные исходники и бинарная презентация заново не читались и не изменялись. Существующая опись docs/review сохраняется; этот отчёт не заявляет полный новый трёхпроходный аудит workspace. Пользовательские untracked материалы не включены в коммиты.
