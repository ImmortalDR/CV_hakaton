## Негативные сценарии, которые легко пропустить

1. Grade нельзя установить через профиль, answers payload, seed или
   демонстрационную привязку ФСП. Проверка должна происходить на сервере.
2. Успешная попытка на одну специализацию не подтверждает другую;
   обновление профиля не должно стирать/переприсваивать подтверждение.
3. Повтор submit после завершения не может заменить оценку; параллельные
   submit/accept не создают несколько результатов/разрешений.
4. Неизвестный стаж не равен 0 и не даёт met для требования 5 лет.
   Нулевое требование не должно делить на 0.
5. Ранжирование не смешивает категории из-за бонуса ФСП. Источник бонуса
   должен указывать demo provider; ввод произвольного ID не является
   реальной верификацией реестром.
6. Полный PDF владельца нельзя кэшировать и возвращать работодателю.
   Нельзя оставить прямой static URL к файлу с контактами.
7. История поиска должна сохранять запрос/порядок, но не удерживать
   контакты после потери права доступа или отзыва публикации.
8. Синтетические профили и эталоны допустимы; метки, вычисленные тем же
   скорингом, не дают независимого измерения. Нужны описание разметки
   команды и ограничения без выдуманного экспертного подтверждения.

## Реально исполненные проверки

`reproduce_findings.py` на оригинальном архиве, после фиксации совместимых
NumPy 2.2.6 / SciPy 1.15.3 / scikit-learn 1.6.1, завершился с кодом 0:

- unknown experience → met при evidence_id=null;
- zero_year_requirement → ZeroDivisionError;
- cyrillic_tokens → [];
- notebook_embedding_scope → NameError device;
- демонстрация ключей i+j: 75 записей, 19 уникальных ключей;
- демонстрация неверной группировки: пересечение 66 из 67 test candidates;
- CSV: 815 строк, 32 точных дубля, 767 уникальных текстов.

Это изолированное воспроизведение, не end-to-end тестирование доноров.
Полное обучение notebook невозможно без отсутствующего hse-hackathon
датасета и не требуется для демонстрации указанных ошибок.

Конвертация исходного PPTX выполнена LibreOffice 24.2.7; просмотрены
монтажи всех 37 слайдов. Числа на шаблонных диаграммах — заполнители,
их нельзя переносить как показатели продукта.

Отсутствующая во вложенной копии SQL-миграция найдена в первоначальном
архиве; её SHA-256 совпадает с манифестом. Исходники не исправлялись.
Общий аудит всех входов остаётся незавершённым.
