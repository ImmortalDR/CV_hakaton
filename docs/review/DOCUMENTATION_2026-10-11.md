## Изменения

- Единый PDF на 20 страниц и DOCX из девяти разделов с содержанием.
- Новые USER_GUIDE.md, DATA_AND_MODELS.md и docs/delivery/README.md.

  навигация и текущая ветка в корневом README.

  Нумерованные шаги не склеиваются; в DOCX повторяются заголовки таблиц,
  строки таблиц не разрываются между страницами.
- check_documentation.py проверяет текущие документы независимо от
  исторического check_delivery.py и старого release-checks.json.

```bash

libreoffice -env:UserInstallation=file:///tmp/fsp-docs-lo-20261011 --headless --convert-to pdf --outdir audit/documentation-20261011/docx-preview docs/delivery/FSP_MVP.docx
.venv/bin/python scripts/check_documentation.py --docx-preview audit/documentation-20261011/docx-preview/FSP_MVP.pdf
git diff --check
```

текстовых блоков за границы страницы. SHA-256 артефактов записаны в
