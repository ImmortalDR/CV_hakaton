# V4-CV: адаптивное продолжение, не новый слепой тест

Зафиксировано после результатов V4, до обучения V4-CV. Первые результаты
сохраняются: выбор по 63 validation-парам дал word cosine; test AP классификатора
0.909 ниже job-only 0.928. Это подтверждает непригодность общей AP как главного
доказательства персонального подбора. В test только три смешанные вакансии.

Используем train+validation V4 как dev, test 77 строк остаётся вне настройки.
4 StratifiedGroupKFold, shuffle=True, seed=20261010, группы — готовые компоненты.
На каждом fold дополнительно удаляем близкие копии из heldout относительно
fold-train. Словари/IDF/scaler обучаются заново. Из неразмеченного корпуса для
fold исключаются heldout-вакансии и близкие копии. Замороженные E5-векторы
переиспользуются; нейросеть не обучается и не подбирается по test.

Фиксированные варианты: word/char/broad/E5 cosine; pairwise dense logistic
C={0.1,1,10}; CatBoost YetiRank depth={3,5}, 250 итераций, lr=.03, seed=20261010.
Новые pointwise-классификаторы не добавляем. Собираем OOF-предсказания каждого
варианта, выбираем параметры и семейство по прежнему правилу: NDCG@10 при
>=10 больших вакансиях, иначе macro within-job AUC при >=5 смешанных, иначе AP
с оговоркой. При равенстве фиксированный порядок, более простой вариант первым.

Сохраняем выбор и OOF до расчёта test. Затем выбранный вариант каждого семейства
обучаем на dev и однократно оцениваем на прежнем test; показываем все результаты,
интервалы по компонентам и отдельный replay. Это адаптивная разработка после
просмотра V4 test, не новая независимая оценка и не основание для автоматического
включения в приложение. Расширенный retrieval benchmark frozen E5/TF-IDF
остаётся без изменений и использует словарь первого V4, не V4-CV.
