# Оценочный набор ФСП

- DeepSeek не использовать без новой прямой команды пользователя. Код сборки не
  читает `.env`, не вызывает LLM и не отправляет исходные записи во внешние API.
- Разметчиков нет. Собственная разметка — программные контрольные сценарии;
  исходные внешние метки сохраняют свой смысл. Не имитировать экспертов.
- Исходные raw_sources и упаковочные материалы сохранять без изменения.
- Рабочую БД приложения не менять. Импорт только в отдельную оценочную БД,
  по умолчанию dry-run. Подтверждённые грейды внешним резюме не присваивать.
- Старый fsp-server-dataset-prompt.md — сохранённый вход. При противоречии
  актуальному заданию использовать пользовательские уточнения и README.md.
- Публичный экспорт только по манифесту разрешённых файлов. Ни `.env`, ни
  исходные реальные профили, ни локальное дополнение автоматически не публиковать.
